# Фронтенд классификатора КТРУ

React SPA по сценарию из `docs/analytics/02-scenario.md` и контракту `contracts/openapi.yaml`.

## Запуск

Нужны **Git** и **Node.js 20.19+ или 22 LTS** (https://nodejs.org, вместе с ним ставится npm). Проверить: `node -v`.
Команды одинаковые для Windows (PowerShell или cmd), macOS и Linux.

```bash
git clone https://github.com/Leshyyyy/ktru.git
cd ktru
git checkout dev            # или ветку с нужными изменениями
cd frontend
npm ci                      # один раз и после изменений package-lock.json
npm run dev                 # открыть http://localhost:5173
```

По умолчанию сервер не нужен: бэкенд имитируется прямо в браузере. Остановить — `Ctrl+C` в терминале.

| Команда               | Что делает                                                                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run dev`         | Встроенная имитация бэкенда (`src/mock`). Обработка задачи «идёт» в реальном времени, данные живут до перезагрузки страницы.                 |
| `npm run dev:prism`   | Фронт + Prism на `:4010` по `contracts/openapi.yaml`. Отдаёт статичные примеры из контракта — проверить, что фронт понимает ответы по схеме. |
| `npm run dev:backend` | Фронт против настоящего бэкенда на `http://localhost:8000` (адрес — в `.env.backend`).                                                       |
| `npm run build`       | Сборка для docker-compose.                                                                                                                   |
| `npm run build:demo`  | Статическая демо-сборка с имитацией в `dist-demo/`.                                                                                          |
| `npm run gen:api`     | Перегенерировать типы `src/api/schema.d.ts` после изменения `openapi.yaml`.                                                                  |
| `npm run typecheck`   | Проверка типов.                                                                                                                              |

Режимы задаются файлами `.env`, `.env.prism`, `.env.backend`, `.env.production`, `.env.demo`. Свои локальные настройки кладите в `.env.local` — он не попадает в git.

Частые проблемы:

- `npm ci` ругается на версию Node или Vite не запускается — обновите Node до 22 LTS.
- Порт 5173 занят — Vite сам возьмёт следующий свободный и напишет адрес в терминале.
- На Windows PowerShell пишет «выполнение сценариев отключено» — запускайте команды в cmd или выполните `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

В docker-compose фронт собирается `Dockerfile` из этой папки: nginx без root (порт 8080) отдаёт SPA и проксирует `/api/` в сервис `api:8000`; имя `api` перерешивается при каждом запросе, поэтому перезапуск api не ломает фронт.

## Как устроено

```
src/
  api/
    schema.d.ts   типы, сгенерированные из openapi.yaml (руками не правим)
    types.ts      короткие имена для этих типов
    client.ts     типизированный клиент (openapi-fetch); режим memory/http — подмена fetch
    hooks.ts      запросы и мутации через TanStack Query: опрос прогресса, кэш, обновление после правок
  mock/           имитация бэкенда для режима memory (тот же контракт, данные в памяти вкладки)
  pages/          экраны: загрузка и колонки, список задач, результаты задачи, качество
  components/     раскладка, бейджи уверенности и статусов, карточка позиции
  lib/format.ts   подписи статусов, цвета зон уверенности, форматирование чисел и дат
```

Ключевые решения:

- **Контракт — источник правды.** Типы генерируются из `openapi.yaml`; если бэкенд поменяет поле, сборка фронта упадёт на проверке типов, а не у пользователя.
- **Имитация за `fetch`.** Код страниц не знает, с чем работает: с имитацией, Prism или настоящим бэкендом. Режим выбирается переменной `VITE_API_MODE`.
- **Пороги цветов приходят из `/config`**, а не зашиты во фронт: калибровку меняет ML, интерфейс подстраивается сам.
- **Прогресс — опрос раз в 1,5 с**, как просит контракт. Таблица перезапрашивается, когда меняется число обработанных позиций, поэтому прогресс и таблица не расходятся.
- **Фильтры в адресе страницы** (`?band=red&sort=confidence_asc`): ссылкой можно поделиться, они переживают обновление.
- **Цвет не единственный носитель смысла:** рядом с цветом всегда число или подпись.

## Стек

React 19, TypeScript, Vite 7, Mantine 8 (компоненты), TanStack Query 5 (данные с сервера), React Router 7, openapi-typescript + openapi-fetch. Шрифты Onest и JetBrains Mono, тема по макетам из `docs/team/` (только светлая).
