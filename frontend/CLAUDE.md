# Фронтенд — правила для Claude

Владелец зоны — Таир. Общие правила проекта — в корневом `CLAUDE.md`; здесь только то, что касается `frontend/`.

## Источник правды

- API — `contracts/openapi.yaml`. Типы генерируются: `npm run gen:api` → `src/api/schema.d.ts`. Руками этот файл не правим.
- Макеты — `docs/team/` («Описание интерфейса», «Экраны.html», PNG экранов). Макет — ориентир по виду, логику берём из контракта.
- Нужна правка контракта — не меняй `contracts/`, напиши, что и зачем; её согласуют отдельным PR.

## Структура

- `src/api/client.ts` — клиент openapi-fetch; режим `memory`/`http` = подмена `fetch`. Страницы не знают, с чем работают.
- `src/api/hooks.ts` — все запросы через TanStack Query. Новые запросы добавляй сюда, а не `fetch` в компонентах.
- `src/mock/` — имитация бэкенда для режима `memory`. Меняешь поведение API в контракте → поправь и имитацию.
- `src/components/badges.tsx` — уверенность, статусы, флаги, группы, код КТРУ. Используй их, не рисуй заново.
- `src/lib/format.ts` — все подписи статусов и флагов по-русски, проценты, даты, склонения.
- `src/theme.ts`, `src/global.css` — тема по макету: цвета `--k-*`, Onest + JetBrains Mono, радиус 10 px, только светлая тема.

## Правила

- Пороги зон берём из `/config` (`useThresholds()`), не зашиваем 0.85 в код.
- Цвет не единственный носитель смысла: рядом всегда число или подпись.
- Фильтры таблицы живут в адресе страницы (`useSearchParams`).
- Ошибки показываем текстом `message` из ответа API (`ApiRequestError`), без своих формулировок поверх.
- Позиции в `pending` — кнопки решений неактивны (бэкенд ответит 409).
- Целевая ширина 1440 px, минимум 1280; таблица и карточка работают на 768 px.
- Тексты интерфейса — по-русски, обращение на «вы», без канцелярита.

## Команды

- `npm run dev` — имитация в браузере, `npm run dev:prism` — Prism, `npm run dev:backend` — живой API на :8000.
- `npm test` — тесты чистых функций из `src/lib` (встроенный `node:test`, файлы в `test/`).
- `npm test`, `npm run typecheck` и `npm run build` перед каждым PR; `prettier --write src test`.
- В описании PR — скриншот изменённого экрана.
