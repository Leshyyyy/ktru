# AI-классификатор КТРУ

Кейс-чемпионат B2B-РТС, задача 5. Документация собирается Sphinx:

```bash
pip install -r requirements-docs.txt
sphinx-build -W -b html docs docs/_build/html
```

* `docs/` — системная аналитика и страницы контрактов
* `contracts/` — `openapi.yaml`, `schema.sql`, `ml_contracts.py`, `stub_pipeline.py`, `fixtures/`
