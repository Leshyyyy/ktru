# 1. Цель, границы и допущения

Система принимает спецификацию товаров (xlsx, csv, pdf), извлекает из каждой строки атрибуты, подбирает код КТРУ с оценкой уверенности, а человек проверяет и правит результат. Цель первого тура — закрыть 7 критериев приёмки задачи 5 и показать работу в видео до 5 минут.

**Входит в первый тур**

- Загрузка файлов, выбор листа и сопоставление колонок.
- Извлечение атрибутов: наименование, бренд, модель, характеристики, количество, единица измерения.
- Подбор кода КТРУ: топ-3 варианта, уверенность в процентах, пояснение.
- Пакетная обработка до 1000 позиций через очередь, прогресс, возможность закрыть вкладку.
- Ручная правка кода с поиском по каталогу, подтверждение, сохранение правок как эталонов.
- Экспорт результата в xlsx и csv.
- Обновление каталога КТРУ без передеплоя.
- Страница качества: метрики на размеченном наборе.

**Не входит**

- Авторизация и несколько пользователей: организаторы этого не требуют, все данные видны всем.
- Интеграция с ЕИС «вживую» и подача закупок.
- Дообучение моделей во время работы системы; дообучение выполняется отдельно, офлайн.
- Языки кроме русского.

**Допущения до ответа организаторов**

| № | Допущение | Если ответ другой |
| --- | --- | --- |
| A1 | «Правильный ответ» — полный код КТРУ с суффиксом. Дополнительно считаем совпадение на уровне ОКПД2. | Если достаточно ОКПД2, метрика проще, поиск идёт в два шага. |
| A2 | Каталог КТРУ берём из ЕИС и храним снимком с номером версии. | Если дадут свой файл, меняется только скрипт импорта. |
| A3 | Тестового набора организаторов нет, строим свой: 300 позиций, у 50 из них дополнительно размечены атрибуты. | Если дадут набор, он становится закрытым контрольным. |
| A4 | LLM по умолчанию локальная; облачная включается переменной окружения. | Если разрешат облако и дадут ключ, облачный режим становится основным для демо. |
| A5 | Проверяющие запускают проект на машине без GPU. | Если есть GPU, включаем GPU-профиль compose. |
| A6 | Лимиты: файл до 50 МБ, до 5000 строк, до 1000 позиций в одном запросе обработки. | Меняются в конфиге. |
